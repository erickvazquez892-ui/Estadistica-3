¡Te damos la bienvenida!

Estadística para todos es una potente plataforma web diseñada para democratizar el análisis de datos. Tanto si eres estudiante, docente, investigador o analista, aquí encontrarás un espacio interactivo para entender las historias ocultas detrás de tus números.

¿Cómo funciona?

  1. Carga tus datos: Usa el dataset de demostración o sube tu propio archivo CSV.
  2. Configura tus variables: Personaliza nombres, tipos de variables y maneja valores nulos.
  3. Explora los módulos: Análisis descriptivo, correlaciones y pruebas de normalidad.
  4. Genera y descarga: Exporta tus resultados fácilmente.
